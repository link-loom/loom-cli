# Sommatic client

Build the client web app of **Sommatic**, the cognitive layer an organization operates with, for the people who run
the operation.

- Product name: **Sommatic**. In one sentence: "The cognitive layer that interprets, decides and operates."
- People sign in with Veripass, and new organizations can sign up.
- It belongs to the StoneOS ecosystem and has the Sommatic Command Center.
- Advanced settings shows only the Identity, Intelligence and Analytics platforms.
- The interface opens in English.
- Brand: Sommatic's dark purple. Header #3a2e4f and primary colour #3a2e4f; the logo area a touch darker.
- People manage **agents** (in the cognitive-infrastructure domain of the backend): each one has a name (required), a
  long objective and whether it is enabled. They want to see them as cards first, with a quick view and copying an
  agent's ID. In Spanish they are "Agente" / "Agentes".

When you are done the project must pass its own verification.
